# המרחב המתמטי

המאגר: `eyez81/math-grids`. קוד המקור נמצא בתיקיית `source`, והאתר שנבנה נמצא בתיקיית `docs`.
GitHub Pages: branch `main`, folder `/docs`. הקובץ `docs/.nojekyll` חייב להישאר.

היישומון מבוסס על קובץ המקור שהועלה. נוספו שמות לצירים, הסתרת צירים, כיתוב משוואת הישר וערכי המדדים לצד מתגי התצוגה במאפייני האובייקט, וכן עזרה וחיפוש כלים.
